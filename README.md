# SRE Education OS

A comprehensive Site Reliability Engineering (SRE) knowledge base with runbooks, guides, checklists, and templates.

## Structure

| Folder | Contents |
|--------|----------|
| `runbooks/` | Step-by-step operational runbooks |
| `docs/` | SRE concepts, SLO/SLA/SLI guides |
| `checklists/` | On-call and deployment checklists |
| `templates/` | Postmortem and incident templates |

## Quick Start

1. Start with `docs/sre-fundamentals.md` to understand core principles
2. Use `checklists/on-call-checklist.md` when going on-call
3. Reference `runbooks/` during incidents
4. File a postmortem using `templates/postmortem-template.md`
