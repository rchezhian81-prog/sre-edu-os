# On-Call Checklist

## Starting Your On-Call Shift

- [ ] Confirm handoff with previous on-call engineer
- [ ] Review open incidents and any ongoing issues
- [ ] Check alert noise — silence any known false positives
- [ ] Verify your pager/phone is working and alerts are routing correctly
- [ ] Review changes deployed in the last 24 hours
- [ ] Check capacity dashboards — any services near limits?

## During On-Call

- [ ] Acknowledge alerts within SLA time
- [ ] For SEV-1/SEV-2: immediately open incident bridge
- [ ] Document all actions taken during incidents
- [ ] Update status page for user-facing incidents
- [ ] Escalate if you need help — never struggle alone

## Ending Your On-Call Shift

- [ ] Hand off any open issues to incoming on-call
- [ ] Share summary of incidents, toil, and alerts
- [ ] File tickets for any recurring issues
- [ ] Log toil items for automation follow-up

## Escalation Path
1. On-call SRE
2. Senior SRE / Tech Lead
3. Engineering Manager
4. VP Engineering (SEV-1 only)
